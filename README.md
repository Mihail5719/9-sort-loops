# 9-sort-loops

Реализация сортировки массива алгоритмом **«Пузырьковая сортировка» (Bubble Sort)** на JavaScript с использованием вложенных циклов.

## 📁 Структура
- `index.html` — файл с кодом сортировки и выводом в консоль браузера
- `README.md` — описание проекта

## 🚀 Как запустить
1. Откройте `index.html` в Google Chrome (перетащите файл в окно браузера)
2. Нажмите `F12` → перейдите на вкладку **Console**
3. Вы увидите исходный и отсортированный массив

## 📝 Как работает алгоритм
- Внешний цикл задаёт количество проходов по массиву
- Внутренний цикл сравнивает соседние элементы
- Если левый элемент больше правого, они меняются местами
- После каждого прохода наибольший элемент «всплывает» в конец массива
